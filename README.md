# Obsidian WeChat HTML Exporter

一个用于将 Obsidian Markdown 文档导出为微信公众号兼容 HTML 格式的插件，并提供实时预览功能。

## 功能特性

- 📱 **微信公众号兼容**：生成符合微信公众号排版规范的 HTML
- 👀 **实时预览**：在 Obsidian 中实时查看导出效果
- 🎨 **多种主题**：支持多种预设主题，适应不同风格需求
- 📊 **Mermaid 图表支持**：自动渲染 Mermaid 图表
- 📷 **本地图片处理**：自动处理本地图片，生成微信兼容的图片格式
- ⚡ **一键复制**：快速复制生成的 HTML 代码
- 🔄 **自动刷新**：文件内容变化时自动更新预览

## 安装方法

### 从 Obsidian 插件市场安装（推荐）

1. 打开 Obsidian 设置
2. 进入「社区插件」页面
3. 点击「浏览」按钮
4. 搜索「WeChat HTML Exporter」
5. 点击「安装」按钮
6. 安装完成后启用插件

### 手动安装

1. 从 GitHub 下载最新版本的插件包
2. 将插件包解压到 Obsidian 的插件目录中
3. 重启 Obsidian
4. 在设置中启用插件

## 使用说明

### 1. 打开预览面板

- 打开任意 Markdown 文件
- 在右侧边栏中找到「微信 HTML 预览」图标
- 点击图标打开预览面板

### 2. 查看和复制 HTML

- 在预览面板中可以实时查看生成的 HTML 效果
- 点击「复制」按钮可以将完整的 HTML 代码复制到剪贴板
- 点击「刷新」按钮可以手动刷新预览

### 3. 切换主题

- 在预览面板顶部的设置中可以选择不同的主题
- 支持的主题：
  - 默认主题
  - Tech 主题
  - ChatGPT 主题
  - Deepseek 主题

### 4. 导出 HTML

1. 复制预览面板中的 HTML 代码
2. 粘贴到微信公众号编辑器中
3. 根据需要进行微调
4. 发布文章

## 主题说明

### 默认主题

- 简洁清晰的排版风格
- 适合大多数类型的文章
- 标题使用默认黑色
- 强调色：#0366d6

### Tech 主题

- 科技感十足的红色主题
- 适合技术类文章
- h3 标题使用红色（#ff0000）
- 强调色：#ff0000

### ChatGPT 主题

- 模仿 ChatGPT 界面风格
- 适合 AI 相关文章
- h3 标题使用橙色（#d93026）
- 强调色：#d93026

### Deepseek 主题

- 蓝色系主题，专业稳重
- 适合技术深度文章
- h2 标题使用蓝色（#1a6dfc）
- 强调色：#1a6dfc

## 注意事项

1. **图片处理**：插件会自动处理本地图片，但建议使用相对路径引用图片
2. **格式兼容性**：部分 Obsidian 特有的 Markdown 语法可能无法在微信公众号中正常显示
3. **Mermaid 图表**：生成的图表会转换为图片，确保图表内容简洁明了
4. **代码块**：支持代码高亮，建议使用合适的代码语言标识
5. **外部资源**：微信公众号不支持外部 CSS 和 JavaScript，插件会将所有样式内联

## 支持的 Markdown 语法

- 标题（# h1, ## h2, ### h3）
- 段落和换行
- 粗体（**粗体**）
- 斜体（*斜体*）
- 链接（[链接文本](链接地址)）
- 图片（![图片描述](图片地址)）
- 列表（有序列表、无序列表）
- 代码块（```代码```）
- 引用（> 引用内容）
- Mermaid 图表（```mermaid 图表代码```）
- 表格

## 常见问题

### Q: 图片无法正常显示怎么办？
A: 请确保图片路径正确，使用相对路径引用图片，避免使用绝对路径。

### Q: Mermaid 图表没有渲染怎么办？
A: 请确保 Mermaid 代码格式正确，插件会自动渲染符合规范的 Mermaid 图表。

### Q: 生成的 HTML 在微信公众号中排版错乱怎么办？
A: 微信公众号编辑器可能会对 HTML 进行一些处理，建议在粘贴后检查排版，必要时进行微调。
